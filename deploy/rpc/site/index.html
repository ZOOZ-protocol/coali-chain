How Proof of Trust works

Comment fonctionne le Proof of Trust

  • Founders (3 nodes today, in Falkenstein, Nuremberg and Helsinki) bootstrap the network.
  • Anyone can become a validator if they are identity-verified on Coali / Popolitica and receive at least 1 public trust from other users (threshold set on chain, will grow).
  • The set is recomputed every session (5 minutes), most-trusted first.
  • A validator that stops producing blocks for ~12 minutes is set aside automatically, so a few offline nodes can never stop the network.
  • Les fondateurs (3 nœuds aujourd'hui, à Falkenstein, Nuremberg et Helsinki) démarrent le réseau.
  • Tout le monde peut devenir validateur s'il est vérifié (KYC) sur Coali / Popolitica et reçoit au moins 1 trust public d'autres utilisateurs (seuil fixé sur la chaîne, il augmentera).
  • La liste est recalculée à chaque session (5 minutes), les plus « trustés » d'abord.
  • Un validateur qui ne produit plus de blocs pendant ~12 minutes est écarté automatiquement : quelques nœuds en panne ne peuvent pas bloquer le réseau.

Run a node

Lancer un nœud

A small Linux server is enough (2 vCPU, 4 GB RAM, 80 GB disk, ~5 €/month), always on. Connect with the chain spec and Docker image, generate session keys with author_rotateKeysWithOwner, set them with session.setKeys, then send your validator address to the Coali team so it is linked to your verified account. Full guide: Run a validator.

Un petit serveur Linux suffit (2 vCPU, 4 Go de RAM, 80 Go de disque, ~5 €/mois), allumé en permanence. Connectez-le avec la chain spec et l'image Docker, générez vos clés de session avec author_rotateKeysWithOwner, enregistrez-les avec session.setKeys, puis envoyez votre adresse de validateur à l'équipe Coali pour qu'elle soit liée à votre compte vérifié.
